本页是当前小程序三页 UI 的离线 H5 镜像，逐像素对齐 chat.wxss / jury.wxss / sessions.wxss 的最终代码（含 v62 三阶段 + v63 数据驱动可视化）。下方左列是已覆盖的 UI 能力，右列是去真机一一核对的步骤。

✦已覆盖的 UI 能力

①
空态 onboarding — 脉冲头像、语料计数、横排切大佬、starter 气泡。
②
analyzing 徽章 — Phase1 取数绿色卡转圈，工具 pill 逐个打勾。
③
完整答案卡 — 深色 ticker 条 + 判决横幅（置信度环）+ PE 估值标尺 + 股息 vs 国债对比 + 成长体检四宫格 + 五维体检 + 重点关注。
④
工具折叠 + markdown 正文 — 内心分析、工具结果预览、分层小节、有序/无序列表、#N 引用 chip、followups、quotes（相关性 + 时效徽章）。
⑤
多人对线 jury — 双 sage 并行卡，状态徽章（分析中/落笔中/已审✓）、各自的判决横幅 + 紧凑 viz。
⑥
历史列表 — 搜索框 + 会话卡 + 四态判决徽章 + 生成中脉冲高亮。

✓真机验证步骤

  1. 微信开发者工具打开 sage-jury/miniprogram，编译到模拟器或真机预览。
  2. 空态对照框①：脉冲动画、10497 / 33877 语料数、两位大佬色卡（蓝 #3b82f6 / 绿 #10b981）。
  3. 问「招行 PE 分位」走一轮：看 analyzing 卡 → ticker 条 → 判决横幅置信度环是否顺时针填到对应百分比。
  4. 展开判决卡：核对 PE 游标位置、股息 ＞ 国债对比条与利差文案、成长四宫格涨跌色、五维通过/未过圆点。
  5. 点正文 #N 引用 chip → 应高亮滚动到对应 quote；长按 quote 复制原帖链接。
  6. 头部「多人对线」进 jury：勾 2 位大佬提问，核对两卡并行流式与各自判决。
  7. 回 sessions 列表：核对判决徽章四态配色与生成中脉冲点。
