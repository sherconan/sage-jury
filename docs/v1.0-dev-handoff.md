# 🔴 P1 · 美股深度档案 [V1.0 卡点]

**Sprint**: S1 (W1-2) ｜ **工时**: 5 人日 ｜ **优先级**: P0

### Background
v62 当前只有 A 股段永平真分析（茅台/招行）。**苹果是段永平第一票**——他从 2002 起重仓 22 年，没苹果不算段永平 agent。当前苹果走 thin 档案，回答泛泛而谈。

### 验收标准（Acceptance Criteria）
- ☐ `curl POST .../api/chat/v2/stream` 问"苹果能买吗" → 回答含 5 个〔〕分层（结论/生意本质/现在的价/能力圈+周期/仓位+边界）
- ☐ 回答里有真实 10 年数据：营收 CAGR / ROE 趋势 / EY vs 国债 / 毛利率
- ☐ verdict 事件 `v62: true, depth: "full"`（不再是 thin）
- ☐ 英伟达 / 拼多多 / 网易 同样跑通

### Tech Spec

**入口**：`lib/sage/v62/research.ts` 的 `buildDossier` 函数
当前 if `ticker.market !== 'A'` 走 thin 分支返回，要加 US 完整分支。

**数据源候选**（必须探明可用的）：
| 候选 | 路径 | 风险 |
|---|---|---|
| akshare `stock_us_fundamental_xueqiu_em` | Python 后端代理 | 要起 Python 服务，edge function 调不到 |
| eastmoney 美股 datacenter RPT | 仿 A 股 RPT_F10_FINANCE_MAINFINADATA | 真实 RPT 名待探（盲探 5 个失败） |
| cninfo 美股 | 国际板块 | 覆盖度未知 |
| stockanalysis.com / wisesheets | 国外免费源 | 可能限流 |

**Plan B**: 如免费源全失败 → 起 Python service 做 akshare 代理（部署在 Vercel functions / 自建服务器）

### 实现拆解
1. ☐ I1.1 探明美股 10 年财务源（试 5 个候选，选可用的）— 1 人日
2. ☐ I1.2 `lib/sage/v62/research.ts` 加 `fetchUSFinancials` + US 分支整合 — 1.5 人日
3. ☐ I1.3 `lib/sage/stock_tools.ts` `NAME_TO_US` 字典扩到 30 只主流美股 — 0.5 人日
4. ☐ I1.4 端到端测试：苹果/英伟达/拼多多/网易 4 票本机 dev 跑通 — 1 人日
5. ☐ I1.5 部署上线 + 线上回归 + 文档更新 — 1 人日

### 改动文件
- `lib/sage/v62/research.ts`（主，新增 fetchUSFinancials + US 分支）
- `lib/sage/stock_tools.ts`（NAME_TO_US 字典）
- `docs/PROJECT-HANDOFF.md` §5 数据源表更新
- 如走 Plan B：新增 `services/akshare-proxy/`（Python service）

### Definition of Done
- ☐ tsc + build 通过
- ☐ 4 票端到端测试 acceptance criteria 全过
- ☐ PR merge to main
- ☐ vercel --prod 部署成功
- ☐ 文档更新

### Risks & Mitigation
- 风险：免费源全没 → Plan B akshare 代理

# 🟡 P4 · Reflection Loop

**Sprint**: S2 (W7) ｜ **工时**: 3 人日 ｜ **优先级**: P1

### Background
当前 LLM 写完就出，没自检"像段永平吗 / 数字用对了吗 / 有没有空话金句"。质量不稳定。

### 验收标准
- ☐ 10 题 AB 测：reflection on vs off，盲评 v62+reflection 胜出 ≥ 7 题
- ☐ reflection 不达标时 regen 1 次（最多 1 次，控延迟）

### Tech Spec
`route.ts` LLM 流式完成 → 立即 LLM-judge call（短 prompt：判 4 项 0-2 分）→ 总分 < 6 触发 regen。

### 实现拆解
1. ☐ I4.1 设计 judge prompt（4 项判分：voice / 数字 / 信息密度 / 段永平魂）— 0.5 人日
2. ☐ I4.2 `route.ts` 加 LLM judge call + regen 逻辑 — 1 人日
3. ☐ I4.3 AB 测 10 题盲评 — 1 人日
4. ☐ I4.4 部署 + 文档 — 0.5 人日

### 改动文件
- `app/api/chat/v2/stream/route.ts`（主）
- 新增：`lib/sage/v62/reflect.ts`（judge prompt + 解析）
