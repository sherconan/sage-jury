# sage-jury V1.0 交付 — Goal / OKR

> 用 OKR 模式拆「V1.0 交付」：1 个 Objective + 5 个 Key Results。
> 每个 KR 都是「可衡量、有数字、有完成标准」的。

---

## Objective（O — 鼓舞人心的目标，定性）

> **3 个月内交付 sage-jury V1.0**：让一个**普通投资者**问段永平 / 管我财关于
> A 股 / 港股 / 美股**任意一只主流标的**，都能得到一份**用大佬真实投资逻辑**
> 算出来的、有数字、有判断、有边界的**深度分析**——而不是泛泛而谈或"我看不懂"。

---

## KR 详解 + 工作拆解

### 🎯 KR1 · 覆盖广度（最大短板）

**当前**：A 股段永平有 v62 真分析，其他都是 v61 thin。
**目标**：A/H/美 × 段永平+管哥，**核心 60 标的**走深度。

**Must do**：
- [ ] 美股 10 年财务源（akshare? cninfo 美股? eastmoney 美股 datacenter 接口探明）—— **苹果是段永平第一票，必做**
- [ ] 港股 10 年财务源（gtimg 只有当期，要找历史；或 xueqiu MCP 后端代理）
- [ ] 管哥 v62 化（analyzeGuan：分位/排雷/股息/稳态/荒岛 5 维度 × 10 年）
- [ ] 标的字典扩到 60（NAME_TO_TICKER / NAME_TO_US 扩，覆盖常被问的票）

**完成定义**：测试矩阵 60 题（60 标的 × 段永平），≥ 54 题（90%）回答含 5 个〔〕分层 + 真数字算账。

### 🎯 KR2 · 分析质量

**当前**：茅台 v62 输出 926 字、5 分层、真数字、传记锚——单点 V1.0 水准。
**目标**：盲评 v62 vs v61 老路 → 70%+ 用户选 v62。

**Must do**：
- [ ] reflection loop：LLM 写完自检（"像段永平吗 / 数字用对了吗 / 有没有金句空话"）→ 不达标 regen 一次
- [ ] 定性维度接入：cninfo 致股东信、eastmoney 回购数据、xueqiu 高管动向
- [ ] "看十年" 第 5 维度：让 LLM 推 10 年后行业格局/风险/增长
- [ ] 全维度判断：不只财务代理，加入管理层质量、企业文化、用户口碑代理指标

**完成定义**：10 题盲评（茅台/苹果/腾讯/招行/拼多多等），v62 胜出 ≥ 7 题。

### 🎯 KR3 · 响应稳定性

## "Goal 模式怎么写" — 给你下次自己用的模板

写 OKR 的 3 条铁律：

1. **O 是定性的，KR 是定量的**
   - ❌ O 写"提升产品质量"（太虚） ✅ O 写"让普通用户问任何主流标的都能得到真分析"
   - ❌ KR 写"提升用户满意度" ✅ KR 写"10 人盲评胜率 ≥ 70%"

2. **KR 要可达成又有挑战**
   - 50% 把握能完成 = 太保守
   - 30% 把握能完成 = 太激进
   - **50-70% 把握** = 刚好

3. **每个 KR 必须有「完成定义」**
   - 否则就是口号
   - 完成定义 = 谁来判 + 怎么判 + 通过线

**模板填空**：

```
## Objective
[时间] 内，让 [用户角色] 在 [核心场景] 中，
能 [鼓舞人心的可衡量结果]。

## KR1（最关键的能力广度/覆盖）
当前 [数字] → 目标 [数字]
完成定义：[具体怎么验收]

## KR2（最关键的质量指标）
当前 [基线] → 目标 [挑战值]
完成定义：[盲评 / A/B / 用户调研 ...]

## KR3（最关键的稳定性/可靠性）
...

## KR4（最关键的真实使用 / 商业）
...

## KR5（最关键的护城河 / 后续可持续）
...
```

**写完后自查 3 问**：
1. 这 5 个 KR 都达成了，O 是不是就达成了？（对齐性）
2. 哪个 KR 是真正的卡点？资源是不是给到了？（聚焦性）
3. 3 个月后我看这份 OKR，能不能一眼判断哪些做到了？（可衡量）
